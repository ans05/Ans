# Spotlight Productivity

A Chrome extension with a Pomodoro timer, task manager, and website blocker.

## Load it locally
1. Open `chrome://extensions` and enable **Developer mode**.
2. Click **Load unpacked** and select this folder.

## Features
- **Pomodoro timer** – 25-minute timer that keeps running with the popup closed and sends a notification when done.
- **Tasks** – add, check off, and remove tasks; they persist between sessions.
- **Website blocker** – closes tabs for blocked sites (and their subdomains); synced across your Chrome profile.
